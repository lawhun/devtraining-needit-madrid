Critical Reminders
⚡

Get Insurance Quotes First

For any Florida or Gulf Coast property. Coastal insurance runs $12K–$25K/yr — always get actual quotes before any offer. Never trust the "35% OpEx" rule.

🗺

Verify Zoning in Writing

Cocoa Beach: call (321) 868-3238. Gulf Shores: call (251) 968-2425. Get a written zoning letter confirming STR is a permitted use before submitting any offer.

📊

Pull AirDNA Comps

Run AirDNA MarketMinder or Rabbu on any specific address before offering. Trailing 12-month gross revenue for comparable active listings validates every pro forma.

🏦

Confirm DSCR Lender Math

Ask exactly how they calculate DSCR for STRs. Florida insurance can fail DSCR qualification. Lock a pre-approval before making an offer — not after.
